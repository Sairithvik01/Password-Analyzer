Cryptography Concepts

Shannon Entropy

Measures the randomness and unpredictability of a password. Calculated as: H = L x log2(C) where L is length and C is character pool size. Higher entropy = more secure.

Brute Force Math

Time to crack = Total Combinations / (Guesses per Second x 2). At 100 billion guesses/second (modern GPU cluster), a 70-bit password would take approximately 36 years to crack on average.

Salted Hashing

Adding random "salt" to passwords before hashing prevents rainbow table attacks. Example: SHA256(password + random_salt) makes precomputed hash tables useless.

Dictionary Attacks

Attackers use lists of common passwords and words. Our analyzer checks against the 50 most common passwords. Real-world systems use much larger dictionaries of known breached passwords.

Pattern Detection

Sequential patterns (abc, 123) and repetitions (aaa, 1111) reduce entropy. Keyboard paths (asdf, qwerty) are especially weak because attackers test these patterns first in dictionary attacks.

Password Reuse Risk

If one service is breached, attackers try stolen credentials elsewhere. Systems should track previous passwords and prevent reuse to minimize lateral damage from compromised credentials.
